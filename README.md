## Запуск КТ-04

Отдельный стенд PostgreSQL 17.11: `deploy/kt04/compose.yaml`. Нужны Go 1.22+ и Docker Compose. Секреты создаются вне репозитория. Порядок сборки и запуска отдельных этапов — в [инструкции](docs/kt04/README.md#запуск).

Сохранённые проверки: [права, RLS и TLS](artifacts/kt04/security.json), [restore](artifacts/kt04/restore.json), [репликация](artifacts/kt04/replication.json), [отказы](artifacts/kt04/failures.json), [аналитика](artifacts/kt04/analytics.json), [lag](artifacts/kt04/lag.json), [PITR](artifacts/kt04/pitr.json).

## Запуск КТ-03

Нужны Docker Compose, Go 1.22+ и make. Из корня репозитория:

```sh
make kt03-all
```

Команда генерирует и проверяет оба набора, выполняет сценарии и замеры, обновляет отчёт. Учебные базы `transport_kt03_dev` и `transport_kt03` пересоздаются.

`make` показывает отдельные команды; `make kt03-package` собирает архив сдачи.

## Где что находится

- `docs/` — отчёты и приложения, сгруппированные по КТ.
- `artifacts/kt03/` — [оглавление результатов](artifacts/kt03/README.md), примеры, планы и измерения.
- `artifacts/kt04/` — результаты проверок безопасности, репликации и восстановления.
- `cmd/`, `internal/` — исходники Go: генератор, запуск и проверки.
- `migrations/`, `sql/`, `tests/` — схема, бизнес-запросы, транзакционные сценарии и проверки SQL.

В `compose.yaml` задан стенд прежних КТ; КТ-04 использует отдельный `deploy/kt04/compose.yaml`. В `go.mod` — модуль Go. Команды прежних КТ доступны через корневой `Makefile`, КТ-04 запускается через `cmd/kt04`.
