## Запуск КТ-03

Нужны Docker Compose, Go 1.22+ и make. Из корня репозитория:

```sh
make kt03-all
```

Команда генерирует и проверяет оба набора, выполняет сценарии и замеры, обновляет отчёт. Учебные базы `transport_kt03_dev` и `transport_kt03` пересоздаются.

`make` показывает отдельные команды; `make kt03-package` собирает архив сдачи.

## Где что находится

- `docs/` — отчёты и приложения, сгруппированные по КТ.
- `artifacts/kt03/` — [оглавление результатов](artifacts/kt03/README.md), примеры, планы и измерения.
- `cmd/`, `internal/` — исходники Go: генератор, запуск и проверки.
- `migrations/`, `sql/`, `tests/` — схема, бизнес-запросы, транзакционные сценарии и проверки SQL.

В `compose.yaml` задан PostgreSQL, в `go.mod` — модуль Go. Команды запуска доступны через корневой `Makefile`.
