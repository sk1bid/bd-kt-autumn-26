# Клиент PostgreSQL КТ-04

Клиент Go запускает установленный `psql` для каждого обращения. Он подключается к PostgreSQL по TCP с проверкой сертификата и имени сервера. Проверка роли и операция выполняются в одной транзакции. Для запуска внутри контейнера proxy-client:

```bash
export PGHOST=localhost PGPORT=55404 PGDATABASE=transport_kt04 PGUSER=kt04_app
export PGPASSFILE=/run/secrets/kt04_app.pgpass PGSSLROOTCERT=/run/secrets/ca.crt

/work/bin/kt04-client read
/work/bin/kt04-client release --request 00000000-0000-4000-8000-000000000004
/work/bin/kt04-client watch --iterations 30 --interval 1s
```

- `read` выводит наряды и число записей по статусам. Для чтения с реплики выберите `PGPORT=55405`, `PGUSER=kt04_analyst` и соответствующий файл паролей.
- `release` вызывает `transport.release_duty` для учебного наряда 1 от имени диспетчера 2 с временем `2026-09-22T09:50:00+07:00`. Успех сообщается после подтверждения `COMMIT`. При неизвестном исходе после восстановления связи используйте тот же UUID. Клиент сохраняет остальные аргументы неизменными и сам запись не повторяет.
- `watch` открывает новое соединение на каждой попытке. Каждая строка JSON содержит время начала попытки, длительность в миллисекундах и результат. Код выхода равен 1, если все попытки завершились ошибкой.
- На попытку отводится до 5 секунд. Ошибки запросов содержат SQLSTATE, когда он получен от PostgreSQL. Полный вывод `psql` и параметры подключения в журнал не попадают.
