# КТ-02 · Спринт 2 · 12 баллов

Открыто: 14.09.2026, 00:00. Срок сдачи: 27.09.2026, 23:59.

Цель: перевести концептуальную модель в корректную реляционную схему и освоить базовые операции SQL.

## Обязательно — 7 баллов

- Разработать логическую модель PostgreSQL: таблицы, атрибуты, первичные и внешние ключи, кардинальности связей.
- Привести модель к третьей нормальной форме. Намеренную денормализацию оформить отдельным решением с обоснованием.
- Реализовать версионируемые миграции для создания схемы с нуля.
- Настроить подходящие типы данных, NOT NULL, UNIQUE, CHECK, внешние ключи и последовательности или identity-столбцы.
- Подготовить небольшой согласованный набор тестовых данных.
- Реализовать SQL-сценарии жизненного цикла не менее трёх основных сущностей. Механический CRUD для каждой таблицы не требуется.
- Добавить негативные примеры, подтверждающие работу минимум пяти ограничений целостности.

## Желательно — до 3 баллов

Выполнить любые три пункта:

- Составить словарь таблиц и атрибутов.
- Автоматизировать проверку схемы и ограничений.
- Обосновать выбор естественных или суррогатных ключей.
- Добавить безопасный сценарий обновления схемы с предыдущей версии.
- Сравнить нормализованную и денормализованную модели одного фрагмента.
- Подготовить матрицу «таблица → владелец данных → бизнес-сценарий».

## Восхитительно — 2 балла

Выполнить один из вариантов:

- Реализовать автоматическую проверку всех миграций на чистой базе и обновления с предыдущей версии.
- Сравнить две физические модели одного фрагмента на одинаковых данных и запросах.
- Разработать набор генеративных или property-based тестов ограничений схемы.
