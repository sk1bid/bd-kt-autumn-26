Полное воспроизведение из корня репозитория:

```sh

```

Нужны Docker Compose, Go 1.22+ и make. Команда пересоздаёт учебные базы `transport_kt03_dev` и `transport_kt03`. Для списка отдельных этапов выполните `make`.
