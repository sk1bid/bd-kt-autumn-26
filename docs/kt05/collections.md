# Словарь документов transport_inspections

Все поля в таблицах обязательны, кроме inspections.note. Типы и ограничения приведены для текущего валидатора MongoDB. В демонстрации все три коллекции используют ObjectId для _id. MongoDB обеспечивает уникальность _id, валидатор отдельно не ограничивает его BSON-тип. ObjectId в ссылке проверяется по типу. Существование документа по этому идентификатору проверяется отдельно.

## procedures — справочник процедур

| Поле | BSON и ограничение | Значение |
|---|---|---|
| _id | ObjectId в примерах | Идентификатор процедуры |
| title | string, от 1 символа | Название, например «Проверка GPS» |
| steps | array из 1–32 уникальных непустых строк | Шаги в порядке выполнения |

## symptoms — справочник симптомов

| Поле | BSON и ограничение | Значение |
|---|---|---|
| _id | ObjectId в примерах | Общий идентификатор симптома для разных актов |
| label | string, от 1 символа | Название для отображения, например «Нет сигнала» |

## inspections — акты осмотра

| Поле | BSON и ограничение | Значение |
|---|---|---|
| _id | ObjectId в примерах | Один акт осмотра |
| deviceId | long, от 1 | Идентификатор устройства в PostgreSQL transport.device.id |
| procedureId | ObjectId | Ссылка на procedures._id |
| observedAt | date | Момент осмотра, BSON Date хранит миллисекунды UTC |
| findings | array из 1–32 объектов | Результаты шагов этого осмотра |
| findings[].step | string, от 1 символа | Название шага на момент выполнения |
| findings[].outcome | строка pass или fault | Результат шага |
| findings[].symptomIds | array из 0–8 уникальных ObjectId | Ссылки на symptoms._id, пустой массив допустим |
| note | необязательно, в CRUD используется string | Примечание инженера. Текущий валидатор допускает дополнительные поля, поэтому тип note им не ограничен |
